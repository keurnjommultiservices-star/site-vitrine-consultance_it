À propos

Un pied sur le chantier, un pied dans le code

Keurnjom Multiservices est porté par Babacar, gérant d'une entreprise de bâtiment qui exerce en parallèle dans la consultance informatique et la conception de sites web.

Cette double pratique se retrouve dans la façon de construire les outils numériques : comme un chantier, chaque projet suit un plan clair, des fondations solides et une livraison qui tient dans le temps — que ce soit un site vitrine, une application de gestion ou un agent IA branché sur WhatsApp Business.

Les clients viennent d'univers concrets — écoles, pharmacies, cabinets médicaux, mairies, entreprises — et repartent avec un outil pensé pour leur usage quotidien, pas pour la démo.
